# Tournament Scoring System
 
A Python-based tournament scoring system developed as part of my BTEC Level 3 Information Technology course.
 
## Overview
 
This application enables the management of a tournament involving both team and individual competitors. The system automates scoring, ranking, and leaderboard generation while enforcing competition rules and validating user input.
 
## Features
 
- Team and individual registration
- Event selection and management
- Automated point allocation
- Leaderboard generation
- Duplicate entry prevention
- Input validation
- Team and participant limits
- Score calculation and ranking
